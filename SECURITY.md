# Security

This policy covers every public repository in the [usewrit](https://github.com/usewrit)
organization that has no `SECURITY.md` of its own. The full policy for Writ is at
[usewrit.app/security](https://usewrit.app/security/).

## Reporting a vulnerability

Please report security issues privately:

- **In a repository:** open the repository's **Security** tab and click **Report a
  vulnerability** (a private GitHub security advisory).
- **In Writ Cloud, Writ Desktop or anything else:** email **security@usewrit.app**.

Do **not** open a public issue, discussion or pull request for an undisclosed vulnerability.

What to expect:

- **Acknowledgement** within 3 business days.
- **Initial assessment** (severity and affected versions) within 7 business days.
- We agree a fix and disclosure timeline with you, and credit you in the published advisory
  unless you prefer otherwise.

## Supported versions

Security fixes go to the latest release of each package or app. Please upgrade before
reporting an issue in an older release.
