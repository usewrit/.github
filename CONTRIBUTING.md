# Contributing to Writ

Thanks for helping. [Writ](https://usewrit.app) gives you your own API to any website; the
repositories in this organization are its open-source parts:

| Repository | What it is |
|---|---|
| [writ-plugins](https://github.com/usewrit/writ-plugins) | The Writ plugin for Claude, Codex, Cursor, Gemini CLI and GitHub Copilot |
| [writ-mcp](https://github.com/usewrit/writ-mcp) | The MCP bridge to Writ Cloud |
| [writ-sdks](https://github.com/usewrit/writ-sdks) | SDKs for TypeScript, Python, Go and Rust |
| [writ-agent](https://github.com/usewrit/writ-agent) | The agent that connects your own machines to Writ |
| [writ-for-websites](https://github.com/usewrit/writ-for-websites) | Guides and examples for running workflows on visitors' computers |
| [writ-desktop](https://github.com/usewrit/writ-desktop) | Writ Desktop downloads and issue tracker (the app is not open source) |

A repository's own `CONTRIBUTING.md`, when it has one, takes precedence over this file.

## Issues

- Search open and closed issues first.
- Say what you ran, what you expected and what happened, with versions.
- **Never paste an API key, a token or a password.** Redact logs before you post them.
- Questions about your account, plan or credits go to
  [usewrit.app/contact](https://usewrit.app/contact/), not to an issue.

## Pull requests

- Keep each pull request to one change, and describe why it is needed.
- Add or update tests for behaviour changes, and make sure CI passes.
- For anything larger than a fix, open an issue first so we can agree on the approach.
- By contributing you agree that your contribution is licensed under the repository's license.

## Conduct

Everyone taking part follows the [Code of Conduct](./CODE_OF_CONDUCT.md).
