# Getting help

- **Documentation:** [usewrit.app/docs](https://usewrit.app/docs/): build an API from a
  website, call it, connect an AI assistant over MCP, run Writ Desktop.
- **A bug in one of these repositories:** open an issue in that repository.
- **Your account, plan, credits or a site that will not work:**
  [usewrit.app/contact](https://usewrit.app/contact/) or support@usewrit.app.
- **A security issue:** see [SECURITY.md](./SECURITY.md). Never in a public issue.
